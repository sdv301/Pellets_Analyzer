# Отчет по модулю «Экономика» (Pellets Analyzer)

## 1. Общее назначение модуля

Модуль экономики реализует **оценку себестоимости производства топливных пеллет** на основе состава сырьевой смеси и параметров заказчика. Он входит в web-приложение `Pellets Analyzer` (Flask) и предоставляет как **расчет единичного состава**, так и **сравнение нескольких сценариев** рецептур.

Модуль позволяет:

- рассчитать себестоимость 1 кг и общих затрат на производство заданной смеси;
- определить необходимое количество топлива (массу, объём, площадь хранения) для работы котла;
- оценить затраты на **хранение**, **производство** и **транспортировку**;
- сравнить несколько рецептур между собой и найти самую экономичную;
- выгрузить результаты сравнения в **Excel** и **PDF**;
- скачать шаблон цен и загрузить собственные цены из Excel в базу данных;
- отобразить результаты на диаграмме (Chart.js) и в виде детализированной таблицы.

## 2. Место модуля в архитектуре приложения

- **Backend-файл:** `app/routes/economics.py` — Blueprint `economics_bp`.
- **Frontend-шаблон:** `templates/economics.html` — страница, расширяющая базовый шаблон `base.html`.
- **Регистрация Blueprint:** выполняется в `app/__init__.py` (`_register_blueprints`) вызовом `app.register_blueprint(economics_bp)`.
- **Настройка пути к БД:** в `app/__init__.py` (`_initialize_extensions`) вызывается `economics.set_db_path(db_path)` для всех модулей, поддерживающих этот метод. По умолчанию это `data/pellets_data.db`.
- **Источник данных:** таблица `components` базы SQLite (поля `component, ro, q, cost_raw, cost_crush, cost_granule` и др.), читаемая через `query_db()` из `app/database/database.py`.
- **Аутентификация:** все маршруты защищены декоратором `login_required` из `app/auth/auth.py`.

## 4. Экономическая модель расчёта

### 4.1 Исходные параметры заказчика

- `q_boiler` — тепловая мощность котла, кВт (по умолчанию 80);
- `t_hours` — время работы котла на запасе, ч (по умолчанию 720);
- `distance` — расстояние транспортировки, км (по умолчанию 258);
- `capacity_factor` — коэффициент загрузки мощности в диапазоне (0, 1] (по умолчанию 0.8);
- `efficiency` — КПД котла в диапазоне (0, 1] (по умолчанию 0.9).

### 4.2 Характеристики компонентов

Для каждого компонента учитываются (в порядке приоритета «справочник → БД»):

- **Ro** — плотность, кг/м³;
- **Qai** — низшая теплота сгорания, МДж/кг;
- **Сс** — затраты на сырьё, руб/кг;
- **Си** — затраты на измельчение, руб/кг;
- **Сг** — затраты на гранулирование, руб/кг.

Встроенный справочник `COMPONENTS_DATA` содержит 13 компонентов (опилки, солома, картон, жмых, шелуха, угольный шлам, торф, бурый уголь, СМС, пластик, листья, отработанное масло, рапсовое масло) с эталонными значениями. Для компонентов, отсутствующих в справочнике, характеристики берутся из БД.

### 4.3 Алгоритм расчёта

1. **Характеристики смеси.** Взвешенные по доле (в %) значения плотности, теплоты сгорания и трёх компонент себестоимости вычисляются как `Σ (доля/100 × характеристика)`.
2. **Необходимый объём топлива (м³):**
   `V = (q_boiler · t_hours · capacity_factor · 3.6) / (Qai · efficiency · Ro)`.
3. **Масса топлива (кг):** `m = V · Ro` (округлённо).
4. **Стоимость хранения:**
   - площадь = `ceil(m / 1100)` м² (норма загрузки 1100 кг/м²);
   - стоимость = площадь × 380 руб/м² (аренда).
5. **Стоимость производства:** `(Сс + Си + Сг) × m`.
6. **Стоимость транспорта:**
   - рейс = `6000 + 85 × distance × 2` (тариф + топливо туда-обратно);
   - число рейсов = `ceil(m / 20000)` (грузоподъёмность 20 т);
   - стоимость = рейс × число рейсов.
7. **Итоговая стоимость = производство + транспорт + хранение.**

Валидируются: положительность состава и теплоты/плотности, диапазон КПД и коэффициента загрузки, положительность мощности и времени, неотрицательность расстояния.

### 5.2 Эндпоинты-обработчики

- **`get_components_economics`** — читает компоненты из БД; если таблица пуста, возвращает данные из справочника. Для каждого компонента отдаёт плотность и три статьи затрат.
- **`download_economics`** — формирует и отдаёт Excel-файл `Шаблон_Цен_Экономика.xlsx` со справочными характеристиками всех 13 компонентов (War, Ad, Qas, Hd, Qai, Сс, Си, Сг), настраивая ширину колонок.
- **`upload_economics`** — принимает Excel, проверяет обязательные колонки (`Компоненты`, `Qai,V, МДж/кг`, `Cc, руб/кг`, `Cи, руб/кг`, `Cг, руб/кг`), очищает таблицу `components` и вставляет новые строки (плотность берётся из справочника по совпадению имени, иначе 1000). Затем сбрасывает кэш карты компонентов.
- **`calculate_economics`** — одиночный расчёт. Меряет время выполнения, валидирует payload, вычисляет результат и возвращает его клиенту в JSON. При ошибке возвращает `{success: false, error}` и логирует traceback.
- **`compare_economics`** — принимает список `scenarios` и вычисляет результат для каждого. Формирует ответ с результатами, находит минимальную итоговую стоимость и имя лучшего сценария.
- **`export_economics_compare_excel`** — пересчитывает сравнение и выгружает в Excel два листа: «Сравнение» (результаты) и «Параметры» (исходные параметры + время формирования).
- **`export_economics_compare_pdf`** — формирует отчёт в PDF (альбомная ориентация) с заголовком, параметрами и таблицей по сценариям: Scenario / Status / Total cost / Mass kg / Storage / Production / Transport.

## 6. Frontend (templates/economics.html)

Страница содержит:

1. **Шапку** с заголовком «Экономическая часть» и бейджем «Модуль расчётов».
2. **Блок ввода параметров** (колонка): мощность, время работы, расстояние, коэффициент загрузки, КПД.
3. **Кнопки импорта/экспорта цен** — «Скачать цены» и «Загрузить цены» (скрытый `<input type="file">`).
4. **Динамический список компонентов** — строки «компонент + процент», сумма в процентах контролируется (должна быть 100), базовые проекты компонентов из справочника; поддержка добавления/удаления строк.
5. **Прогресс-бар** расчёта с анимацией.
6. **Сценарии сравнения** — сохранение текущего состава под именем, список сохранённых сценариев с возможностью удаления, кнопки «Сравнить», «Excel», «PDF».
7. **Блок результатов** — итоговая стоимость, масса/объём/площадь, три карточки затрат (хранение/производство/транспорт), диаграмма-пончик Chart.js, таблица характеристик смеси и таблица сравнения сценариев.

### 6.1 Ключевые JS-функции

- `loadAvailableComponents()` — получает список компонентов через `/api/get_components_economics` и обновляет выпадающие списки.
- `updateTotal()` — пересчитывает сумму процентов и подсвечивает её красным/зелёным (корректно при 100%).
- `collectCurrentScenarioComponents()` — собирает словарь «компонент → процент» из текущих строк.
- `collectGlobalParams()` — собирает глобальные параметры.
- `runScenarioComparison()` — отправляет POST на `/api/compare_economics`.
- `exportScenarios(endpoint)` — скачивает Excel или PDF через соответствующие эндпоинты.
- `renderChart(storage, prod, trans)` — рисует диаграмму затрат (Chart.js, doughnut).

Валидация на клиенте: сумма компонентов должна быть ровно 100% иначе выводится предупреждение (`Swal`). Также обрабатывается частный случай переименования «Отр. моторное масло» → «Отработанное моторное масло».
## 7. Особенности и примечания

- **Кэширование карты компонентов** реализовано через `_db_component_map_cache` с блокировкой `threading.Lock()` и сбрасывается при смене пути к БД или после загрузки цен.
- **Мониторинг производительности:** для эндпоинтов `/api/calculate_economics` и `/api/compare_economics` ведётся журналирование задержек (p50/p95) в кольцевом буфере на 200 записей.
- **Безопасность:** валидация допустимых имён таблиц в `query_db` (`ALLOWED_TABLES`); все маршруты под авторизацией.
- **Надёжность:** обработка исключений с возвратом `{success: false, error}` в JSON вместо падения сервера; в `calculate_economics` traceback выводится в консоль.
- При выгрузке PDF используются шрифты Helvetica (базовые для FPDF), поэтому кириллица в PDF-отчёте не отображается корректно — отчёт формируется на латинице (заголовки колонок на английском).
- Единый модуль поддерживает шахматный вариант: часть логики (справочник, математика) изолирована от сетевой обвязки, что упрощает тестирование (см. `test-project/tests/integration/test_economics_api.py`).

def _compute_economics_result(q_boiler, t_hours, distance, capacity_factor, efficiency, components, db_map):

    STORAGE_LOAD_KG_PER_M2 = 1100.0
    TRUCK_BASE_RATE = 6000.0
    TRUCK_COST_PER_KM = 85.0
    TRUCK_CAPACITY_KG = 20000.0

    mix_ro = mix_qai = mix_cc = mix_cu = mix_cg = 0.0
    for comp_name, percentage in components.items():
        fraction = float(percentage) / 100.0
        ro, qai, cc, cu, cg = _resolve_component_metrics(comp_name, db_map)
        mix_ro += fraction * ro
        mix_qai += fraction * qai
        mix_cc += fraction * cc
        mix_cu += fraction * cu
        mix_cg += fraction * cg

        raise ValueError('Некорректный состав или отсутствуют данные о теплоте сгорания/плотности')

        raise ValueError('КПД должен быть в диапазоне (0, 1]')

    denominator = mix_qai * efficiency * mix_ro

    v_neobh_m3 = mass_kg / mix_ro

    storage_area_m2 = math.ceil(mass_kg / STORAGE_LOAD_KG_PER_M2)
    storage_cost = RENT_COST_PER_M2 * storage_area_m2

    production_cost_per_kg = mix_cc + mix_cu + mix_cg
    production_cost = production_cost_per_kg * mass_kg

    trip_cost = TRUCK_BASE_RATE + (TRUCK_COST_PER_KM * distance * 2)
    trucks_needed = math.ceil(mass_kg / TRUCK_CAPACITY_KG)
    transport_cost = trip_cost * trucks_needed

    total_cost = production_cost + transport_cost + storage_cost
    return {
        'mix_metrics': {
            'density': round(mix_ro, 0),
            'heat_capacity': round(mix_qai, 2),
            'cost_raw': round(mix_cc, 2),
            'cost_crush': round(mix_cu, 2),
            'cost_granule': round(mix_cg, 2)
        },
        'storage': {
            'volume_m3': round(v_neobh_m3, 2),
            'mass_kg': int(mass_kg),
            'area_m2': int(storage_area_m2),
            'cost': round(storage_cost, 2)
        },
        'production': {'cost_per_kg': round(production_cost_per_kg, 2), 'cost': round(production_cost, 2)},
        'transport': {'trip_cost': round(trip_cost, 2), 'trucks': int(trucks_needed), 'cost': round(transport_cost, 2)},
        'total_cost': round(total_cost, 2)
    }


def _extract_global_params(payload: dict):
    global_params = payload.get('global_params', payload)
    try:
        params = {
            'q_boiler': float(global_params.get('q_boiler', 80)),
            't_hours': float(global_params.get('t_hours', 720)),
            'distance': float(global_params.get('distance', 258)),
            'capacity_factor': float(global_params.get('capacity_factor', 0.8)),
            'efficiency': float(global_params.get('efficiency', 0.9)),
        }
    except (TypeError, ValueError):
        raise ValueError('Некорректные числовые параметры расчета')

    if params['q_boiler'] <= 0:
        raise ValueError('Мощность котла должна быть больше 0')
    if params['t_hours'] <= 0:
        raise ValueError('Время работы должно быть больше 0')
    if params['distance'] < 0:
        raise ValueError('Расстояние не может быть отрицательным')
    if params['capacity_factor'] <= 0 or params['capacity_factor'] > 1:
        raise ValueError('Коэффициент загрузки должен быть в диапазоне (0, 1]')
    if params['efficiency'] <= 0 or params['efficiency'] > 1:
        raise ValueError('КПД должен быть в диапазоне (0, 1]')

    return params


def _build_compare_rows(global_params: dict, scenarios: list):
    db_map = _build_db_component_map()
    rows = []
    for idx, scenario in enumerate(scenarios, start=1):
        scenario_name = str(scenario.get('name') or f'Вариант {idx}')
        components = scenario.get('components', {})
        if not components:
            rows.append({'name': scenario_name, 'success': False, 'error': 'Пустой состав'})
            continue
        try:
            result = _compute_economics_result(
                global_params['q_boiler'],
                global_params['t_hours'],
                global_params['distance'],
                global_params['capacity_factor'],
                global_params['efficiency'],
                components,
                db_map
            )
            rows.append({'name': scenario_name, 'success': True, 'components': components, 'result': result})
        except Exception as ex:
            rows.append({'name': scenario_name, 'success': False, 'components': components, 'error': str(ex)})
    return rows

@login_required
def upload_economics():
    import sqlite3
    if 'file' not in request.files:
        return jsonify({'success': False, 'error': 'Файл не найден'})
    file = request.files['file']
    if file.filename == '':
        return jsonify({'success': False, 'error': 'Файл не выбран'})

    try:
        df = pd.read_excel(file)
    except Exception as e:
        return jsonify({'success': False, 'error': f'Не удалось прочитать Excel: {str(e)}'})

    required_cols = ['Компоненты', 'Qai,V, МДж/кг', 'Cc, руб/кг', 'Cи, руб/кг', 'Cг, руб/кг']
    missing = [col for col in required_cols if col not in df.columns]
    if missing:
        return jsonify({'success': False, 'error': f'Неверный формат. Отсутствуют колонки: {", ".join(missing)}'})

    df['Компоненты'] = df['Компоненты'].astype(str).str.strip()
    df = df[df['Компоненты'].str.len() > 0]
    if df.empty:
        return jsonify({'success': False, 'error': 'Файл не содержит данных о компонентах'})

    numeric_cols = ['Qai,V, МДж/кг', 'Cc, руб/кг', 'Cи, руб/кг', 'Cг, руб/кг']
    for col in numeric_cols:
        df[col] = pd.to_numeric(df[col], errors='coerce').fillna(0.0)

    conn = sqlite3.connect(_db_path)
    cursor = conn.cursor()
    try:
        cursor.execute("DELETE FROM components")
        for _, row in df.iterrows():
            name = str(row['Компоненты']).strip()
            ro = COMPONENTS_DATA.get(name, {}).get('Ro', 1000.0)
            cursor.execute("""
                INSERT INTO components (component, ro, q, cost_raw, cost_crush, cost_granule)
                VALUES (?, ?, ?, ?, ?, ?)
            """, (name, float(ro), float(row['Qai,V, МДж/кг']), float(row['Cc, руб/кг']), float(row['Cи, руб/кг']), float(row['Cг, руб/кг']))
            )
        conn.commit()
        _invalidate_component_map_cache()
        return jsonify({'success': True, 'message': f'Цены успешно обновлены! Загружено компонентов: {len(df)}'})
    except Exception as e:
        conn.rollback()
        return jsonify({'success': False, 'error': f'Ошибка записи в БД: {str(e)}'})
    finally:
        conn.close()

@economics_bp.route('/api/compare_economics', methods=['POST'])
@login_required
def compare_economics():
    started_at = time.perf_counter()
    try:
        data = request.get_json(silent=True) or {}
        scenarios = data.get('scenarios', [])
        if not isinstance(scenarios, list) or len(scenarios) == 0:
            return jsonify({'success': False, 'error': 'Добавьте хотя бы один сценарий для сравнения'})
        params = _extract_global_params(data)
        compare_rows = _build_compare_rows(params, scenarios)
        valid_rows = [row for row in compare_rows if row.get('success')]
        min_total = min((row['result']['total_cost'] for row in valid_rows), default=None)
        best_name = next((row['name'] for row in valid_rows if row['result']['total_cost'] == min_total), None)
        return jsonify({
            'success': True,
            'params': params,
            'scenarios': compare_rows,
            'summary': {'best_total_cost': min_total, 'best_scenario': best_name, 'count': len(compare_rows)}
        })
    except Exception as e:
        return jsonify({'success': False, 'error': f'Ошибка сравнения: {str(e)}'})
    finally:
        _record_timing('/api/compare_economics', time.perf_counter() - started_at)

        function loadAvailableComponents() {

                .then(data => {

                        availableComponents = data.components;

                        document.querySelectorAll('.component-select').forEach(select => {
                            const currentVal = select.value;
                            updateSelectOptions(select, currentVal);
                        });
                    }
                });

        function updateSelectOptions(select, selectedValue) {
            select.innerHTML = availableComponents.map(c =>
                `<option value="${c.component}" ${c.component === selectedValue ? 'selected' : ''}>${c.component}</option>`
            ).join('');
        }

        function updateTotal() {
            let sum = 0;
            document.querySelectorAll('.component-percentage').forEach(input => {
                sum += parseFloat(input.value) || 0;
            });

            displayTotal.innerText = sum.toFixed(1);
            if (Math.abs(sum - 100) > 0.1) {
                displayTotal.className = "fw-bold text-danger";
            } else {
                displayTotal.className = "fw-bold text-success";
            }
        }

        function collectCurrentScenarioComponents() {
            const components = {};
            document.querySelectorAll('.component-row').forEach(row => {
                const name = row.querySelector('.component-select').value;
                const perc = parseFloat(row.querySelector('.component-percentage').value) || 0;
                if (perc > 0) {
                    components[name] = (components[name] || 0) + perc;
                }
            });
            return components;
        }
